VPS Backups Rclone

A private backup utility for its owner's server. It uses restic to encrypt selected backup data and rclone to store and verify it in the owner's Google Drive account.

This utility is intended for the owner only. It has no public registration, payment, or file-upload service. This website explains the utility and does not request Google sign-in.

Google Drive access

The requested permission is drive.file: the utility can create and manage its own backup files and other files explicitly made available to this application. It does not request access to the rest of the owner's Drive.

The intended schedule is once per day, retaining seven daily recovery points. Encrypted backups are checked before older recovery points are removed.
